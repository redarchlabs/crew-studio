# Crew Studio

Design, run and inspect [CrewAI](https://github.com/crewAIInc/crewAI) crews from a browser instead of writing Python.

The application lives in [`studio/`](studio/README.md): a Go API with Postgres, a React web console and a Python
runner that executes crews from a frozen configuration. [`QUICKSTART.md`](QUICKSTART.md) sets up the Python
environment, and `./run-stack.sh` starts everything locally.
